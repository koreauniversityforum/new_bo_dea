# 뉴보대 카드뉴스 메이커 — 폰판

한국대학생포럼 대학생 뉴스 계정 [@news_univ](https://instagram.com/news_univ) 의
카드뉴스(1080×1350)를 **폰 브라우저에서 그대로** 만드는 판입니다.
서버가 없습니다. 이 폴더의 정적 파일만으로 돌아갑니다.

## 쓰는 법

주소를 열고 → 기사 본문을 붙여넣고 → `본문 분석` → 문구 후보 중에서 고르고 →
사진 넣고 → `PNG 내려받기`. 끝입니다. 설치도 로그인도 없습니다.

| 화면 | 하는 일 |
|------|---------|
| `index.html` | 카드 만들기 — 문구 자동 후보·사진·디자인·내려받기 |
| `outro.html` | 뒷장(마무리 카드) 만들기 |
| `mark.html`  | 워터마크 설정 (보이는 것 / 안 보이는 것) |

## 되는 것 / 안 되는 것

**됩니다** — 붙여넣은 본문에서 제목·후킹 문구·요약문 후보 자동 생성, 스타일 모드와
브랜드 토큰, 위/아래 띠, 글자별 서체·굵기·색·정렬, 사진 검색(Openverse·위키미디어
공용, 키 없이), 내 사진 넣기, 여러 장 합치기, 워터마크, PNG 내려받기.

**안 됩니다** — 기사 URL 자동 가져오기(브라우저는 다른 사이트의 본문을 읽을 수
없습니다. 그래서 본문 붙여넣기가 기본입니다), 인스타 자동 올리기, out 폴더 정리,
릴스. 이 넷은 서버가 있어야 하는 일이라 PC 앱 쪽에 남아 있습니다.

## 이 폴더는 손으로 고치지 마세요

`newsfeed/static/` 을 고친 뒤 `python 폰판_만들기.py` 로 다시 굽습니다.
빌드가 하는 일은 세 가지입니다.

1. 절대경로(`/static/…`)를 상대경로로 바꿔 하위 폴더 호스팅에서도 깨지지 않게 함
2. 서버가 하던 사진 대리요청을 걷어내고, 캔버스 오염(=저장 실패)을 막는
   `crossOrigin` 을 붙임
3. `summarizer.js`(요약기)와 `폰shim.js`(서버 대역)를 머리에 끼움

요약기는 파이썬 원본(`summarizer.py`)을 옮긴 것이라 결과가 갈리면 안 됩니다.
`python 시험_요약기_대조.py` 가 두 구현을 항목 단위로 맞춰 봅니다.
