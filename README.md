# 뉴보대 — 대학생 뉴스 카드뉴스 메이커

한국대학생포럼(한대포)의 대학생 뉴스 인스타 계정 **[@news_univ](https://instagram.com/news_univ)** 를
굴리는 도구 모음입니다. 기사 하나를 넣으면 인스타에 바로 올릴 수 있는
**1080×1350 카드뉴스**가 나옵니다.

## 폰에서 여는 주소

    https://koreauniversityforum.github.io/new_bo_dea/

깃허브 페이지라 **항상 켜져 있습니다** — 젯슨·터널·열쇠·로그인 전부 필요 없고
주소도 바뀌지 않습니다. 폰 브라우저 메뉴에서 `홈 화면에 추가` 해 두면 앱처럼 씁니다.
바탕화면 `뉴보대 공개 주소 (폰 어디서나).html` 에 같은 주소와 QR 이 들어 있습니다.

🔴 주소를 옮기면 이 README·바탕화면 HTML 의 QR·`docs/` 를 함께 고쳐야 합니다.
   계정은 `park-hyun-su` 가 아니라 **`koreauniversityforum`**, 철자는 `new_bo_dea`
   (`dae` 아님) 입니다 — 2026-08-19 바탕화면 바로가기가 404 났던 이유가 이 둘입니다.

판이 둘입니다.

| | 어디서 | 무엇이 다른가 |
|---|---|---|
| **PC 앱** (`newsfeed/`) | 윈도우 exe / 파이썬 | 기사 URL 자동 수집·요약, 인스타 자동 올리기, 릴스, out 폴더 관리 |
| **폰판** (`docs/`) | 폰·PC 브라우저 | **서버가 없습니다.** 정적 파일만으로 돌아가며 설치·로그인·주소 갱신이 필요 없습니다 |

## 폰판 — 서버 0개

깃허브 페이지로 올리면 폰에서 주소 하나로 바로 씁니다.
기사 **본문을 붙여넣으면** 제목·후킹 문구·요약문 후보를 만들어 주고, 사진을 얹어
`PNG 내려받기` 로 끝냅니다.

- 됩니다 — 문구 후보 자동 생성, 스타일 모드·브랜드 토큰·위/아래 띠·글자별 서체와 색,
  사진 검색(Openverse·위키미디어 공용, 키 없이), 내 사진, 여러 장 합치기, 뒷장, 워터마크
- 안 됩니다 — 기사 URL 자동 가져오기(브라우저는 다른 사이트의 본문을 읽을 수 없습니다),
  인스타 자동 올리기, 릴스, out 폴더 정리 → 이 넷은 PC 앱 쪽에 있습니다

## 만들기

```bash
python newsfeed/폰판_만들기.py     # newsfeed/static/ → docs/ 로 굽는다
```

폰판은 화면 코드를 **복사하지 않습니다.** PC 앱과 같은 `newsfeed/static/` 을 재료로 쓰고,
빌드가 서버에 기대던 부분만 갈아 끼웁니다.

1. 절대경로(`/static/…`)를 상대경로로 — 하위 폴더에 올려도 깨지지 않게
2. 서버가 하던 사진 대리요청 제거 + `crossOrigin` 부착(없으면 캔버스가 오염돼 저장이 막힘)
3. `summarizer.js`(요약기)와 `폰shim.js`(서버 대역)를 머리에 끼움

`폰shim.js` 는 `fetch` 와 `XMLHttpRequest` 를 가로채 `analyze·extract·stock·save·assets`
를 브라우저 안에서 처리합니다. 그래서 `docs/` 를 손으로 고칠 일이 없습니다 —
고칠 곳은 언제나 `newsfeed/static/` 입니다.

## 시험

```bash
python 시험_요약기_대조.py    # 파이썬 요약기 vs JS 이식본 (기사 4건 × 항목 5개)
python 시험_띠.py             # 위/아래 띠·글자 서식
python 시험_스타일모드.py     # 브랜드 스타일 모드
```

요약기는 파이썬(`newsfeed/summarizer.py`)이 원본이고 폰판용 JS 는 그 이식본입니다.
둘이 갈라지면 폰에서만 다른 문구가 나오는데 화면만 봐서는 못 알아채므로,
대조 시험으로 항목 단위까지 맞춥니다.

## 폴더

```
newsfeed/          PC 앱 소스 (파이썬 서버 + 화면 JS + 글꼴·로고)
  static/          화면 — 폰판도 이걸 재료로 쓴다
  폰판_소스/       폰판에만 들어가는 것 (요약기 이식본·shim·README)
  폰판_만들기.py   docs/ 를 굽는 빌드
docs/              폰판 결과물 = 깃허브 페이지로 나가는 사이트
생성_스크립트/     프로필 하이라이트 등 이미지 생성 스크립트
```

`앱/`·`build/`·ZIP 같은 산출물과 제출자 정보가 담기는 CSV 는 저장소에 넣지 않습니다
(`.gitignore` 참고). 다시 구우면 나오는 것들입니다.
